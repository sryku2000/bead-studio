# 豆豆工作室 · 網站發布成品

線上使用：[豆豆工作室](https://sryku2000.github.io/bead-studio/)

本儲存庫只保存正式網站的 HTML、JavaScript、CSS、字型、音樂及第三方授權聲明。
原始碼、Android／iOS 工程與手機上架流程由另一個私有儲存庫管理；這裡不含原始碼提交歷史。

網站的圖片處理、編輯、PDF／PNG 匯出都在使用者自己的瀏覽器執行，無需帳號或 API 金鑰。
作品保存在目前瀏覽器；請使用「儲存專案」下載備份。

此處的檔案由正式建置自動更新，請勿直接修改成品。
GitHub Pages 使用 `main` 分支根目錄發布，`.nojekyll` 表示無需 Jekyll 建置。

散布本站檔案時請保留 `THIRD_PARTY_NOTICES.txt`、`3rdpartylicenses.txt`、
`fonts/OFL.txt` 與 `music/CREDITS.txt`。公開網站成品不代表原創程式碼已授予開源授權。
